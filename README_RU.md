# Minecraft × Teardown: установка и запуск

Это экспериментальный мод, который соединяет две запущенные игры. Подписки в Workshop недостаточно: дополнительно нужен установочный пакет моста из GitHub Releases. Minecraft и Teardown приобретаются и загружаются отдельно.

## Что потребуется

- Windows x64.
- Teardown из Steam, поддерживаемая сборка 25295735. Установщик проверяет совместимость до изменения файлов.
- Prism Launcher: https://prismlauncher.org/download/.
- Учётная запись с Minecraft Java Edition. Поддерживаемая версия — 26.3; профиль пакета задаёт Fabric Loader 0.19.5 и Fabric API 0.161.0+26.3.
- Установочный ZIP моста из раздела Releases проекта, ссылка на который будет указана в описании Workshop. Выбирайте приложенный установочный ZIP, а не автоматически созданный архив Source code.

## Установка

1. Установите Prism, войдите в свою учётную запись Minecraft и один раз запустите Prism. Затем закройте обе игры.
2. Скачайте и распакуйте установочный ZIP в отдельную папку, доступную для записи. Не запускайте файлы прямо из архива.
3. Запустите `INSTALL.cmd`. Он найдёт Teardown и профили Prism, установит мод, отдельную сборку Minecraft и GPU-композитор. Официальный ReShade загружается автоматически с проверкой контрольной суммы.
4. Если установщик сообщает о другой версии Teardown, существующем загрузчике или профиле, прочитайте сообщение: он сохраняет чужие файлы и миры. Не удаляйте их наугад.
5. Перезапустите Prism. В списке появится **Teardown Bridge Workshop**. Запустите её и дождитесь загрузки мира.
6. Оставьте Minecraft открытым, не сворачивайте окно. Переключитесь в Teardown.
7. В меню модов включите **Minecraft x Teardown Bridge**. Откройте песочницу.
8. Запустите `START_BRIDGE.cmd` из распакованной папки. Дождитесь сообщения о подключении Minecraft. Консоль моста оставьте открытой.
9. Вернитесь в Teardown и нажмите **F7**. Появятся предметы и панель Minecraft.

Установочный пакет также добавляет локальную копию Lua-мода. Если одновременно установлена копия из Workshop, включайте только одну из них, чтобы два скрипта не обрабатывали ввод одновременно.

## Управление

| Клавиша | Действие |
|---|---|
| F7 | Включить или выключить мост |
| 1–9 / колесо | Выбрать предмет Minecraft |
| ЛКМ / ПКМ | Атаковать / использовать предмет |
| I | Открыть или закрыть инвентарь Minecraft |
| E | Обычное взаимодействие Teardown: двери, посадка и выход из машины |
| C | При работающем мосте сохраняется вид от первого лица |

Работа мышью внутри инвентаря пока выполняется через окно Minecraft. Музыка Minecraft отключена в профильных настройках. Здоровье Teardown отображается сверху справа.

## Если что-то не работает

- **Нет рук и панели:** проверьте загрузку мира Minecraft, включение Lua-мода, работу консоли моста и F7.
- **Связь пропала:** мост пытается переподключиться. После восстановления нажмите F7, если он автоматически выключился.
- **Ошибка о второй копии моста:** закройте прежнюю консоль. Не запускайте несколько мостов одновременно.
- **После сворачивания Minecraft нет изображения:** восстановите его окно. Поддержка свёрнутого окна не заявлена.
- **Существующий ReShade или неподдерживаемая игра:** установщик не заменяет отличающиеся файлы. Для такой конфигурации нужна отдельная проверка совместимости.
- **Лаги:** начните с обычной песочницы, отключите другие глобальные моды и оверлеи, закройте тяжёлые приложения. Не повышайте разрешение профиля Minecraft до проверки производительности.
- **Вылет:** сохраните `ReShade.log` из папки Teardown, `logs/latest.log` из профиля Prism и `live-link-status.json` из папки `bridge/TDMCBridge`. Перед публикацией журналов проверьте их на личные данные.

## Ограничения первой версии

Поддерживается одиночная игра. Сохранение Teardown не создаёт синхронную резервную копию мира Minecraft. Неровная геометрия, движущиеся поверхности, блоки при быстром движении и приземление жемчуга требуют проверки; известные проблемы перечисляются в примечаниях к конкретному выпуску. Это не официальное дополнение Mojang или Tuxedo Labs.

## Удаление

Выключите мост и закройте обе игры. Запустите `UNINSTALL_NATIVE.ps1` из пакета средствами PowerShell. Он удаляет только добавленные компоненты с совпадающими контрольными суммами и возвращает штатное оформление HUD. Отключите Lua-мод или отпишитесь от него. При необходимости удалите отдельный профиль через Prism; установщик и деинсталлятор не удаляют игровые миры.
